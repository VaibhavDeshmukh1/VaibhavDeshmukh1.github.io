Week four marked the transition from bootcamp training to real infrastructure work. I built a collection pipeline that pulled 1,000 papers from arXiv spanning six months of cs.LG and stat.ML submissions. The system handled the messiness of real data such as papers with multiple versions, API rate limits, and incomplete metadata by tracking base IDs separately from versioned records and using checkpoint logic to resume cleanly after failures.

In parallel, I worked through Notebook 2 on feature extraction. The notebook introduced two competing approaches: rules-based extraction using keyword vocabularies which is fast but limited, and LLM-based extraction using language models which is slower but more accurate. I learned to measure extraction quality using precision and recall, and how to attach evidence to each extracted fact so results stay verifiable rather than opaque.

Using these techniques, I extracted task, method, dataset, metric, and domain from each of the 1,000 papers via OpenAI's API. The challenge was not building the extraction pipeline but writing prompts precise enough to avoid hallucination while flexible enough to handle papers with sparse or missing information.

Professor Chen introduced classification through neural networks and supervised learning using Fashion-MNIST as a teaching example. The core insight was simple: separate training and testing data, or the model will mistake memorization for understanding. This principle shaped everything that followed.

In the final days of week five, I began testing whether the extracted features could predict each paper's arXiv category. Early indications suggest the five features alone are not sufficient signal. The coming week will involve analyzing why, documenting the results, and determining what additional signals might strengthen the classification.
